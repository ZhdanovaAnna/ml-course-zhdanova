# Модуль 2 - House Prices

## Описание

Практическая работа по машинному обучению на датасете **House Prices - Advanced Regression Techniques**.

Цель работы - пройти полный цикл ML-проекта: от исследовательского анализа и предобработки данных до создания признаков, обучения моделей регрессии, оценки качества и предсказания стоимости домов.

## Что выполнено

1) Проведён исследовательский анализ данных (EDA) и построены визуализации
2) Изучены пропущенные значения и выполнена предобработка данных
3) Выполнен Feature Engineering - созданы дополнительные признаки, описывающие характеристики домов
4) Обработаны категориальные признаки с помощью кодирования
5) Выполнено заполнение пропусков в признаках
6) Применено масштабирование признаков с помощью `StandardScaler`
7) Обучены модели **Linear Regression**, **Ridge**, **Lasso** и **ElasticNet**
8) Выполнена оценка качества моделей регрессии
9) Проведено сравнение результатов обученных моделей
10) Реализована функция **predict_price()** для предсказания стоимости дома
11) Выполнено 5 демонстрационных предсказаний для домов с разными характеристиками
12) Предсказания моделей представлены в сравнительной таблице

## Запуск

Клонировать репозиторий:

```bash
git clone <URL-репозитория>
cd module-2-house-prices
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Открыть `notebook.ipynb` в Jupyter Notebook или JupyterLab и последовательно выполнить ячейки.

Перед запуском убедитесь, что исходные файлы датасета находятся в ожидаемой папке и пути к данным соответствуют структуре проекта.

# Модуль 3 - Customer Churn

## Описание

Практическая работа по машинному обучению на датасете **Telco Customer Churn**.

Цель работы - пройти полный цикл ML-проекта для задачи классификации: от исследовательского анализа и предобработки данных до обучения ансамблевых моделей, оценки качества, подбора гиперпараметров и интерпретации результатов.

## Что выполнено

1) Проведён исследовательский анализ данных (EDA) и построены визуализации

2) Изучены пропущенные значения и выполнена предобработка данных

3) Обработаны категориальные признаки и подготовлены данные для обучения

4) Разделены данные на обучающую и тестовую выборки

5) Обучены ансамблевые модели **Random Forest**, **XGBoost**, **LightGBM** и **CatBoost**

6) Выполнена оценка качества моделей классификации

7) Проведено сравнение результатов обученных моделей

8) Выполнен подбор гиперпараметров модели LightGBM с помощью **Optuna**

9) Проведено сравнение базовой и оптимизированной модели

10) Выполнена интерпретация признаков с помощью **SHAP**

11) Сохранены обученные модели и необходимые метаданные

12) Проверена загрузка сохранённой модели и выполнение предсказаний

## Результаты

Качество моделей оценивается с помощью метрик Accuracy, Precision, Recall, F1-score и ROC-AUC. Для задачи оттока клиентов особенно важно учитывать Recall и ROC-AUC, поскольку необходимо выявлять клиентов, которые могут прекратить пользоваться услугами компании.

| **Модель** | **Accuracy** | **Precision** | **Recall** | **F1-score** | **ROC-AUC** |
|---|---:|---:|---:|---:|---:|
| Random Forest | 0.7722 | 0.5575 | 0.6872 | 0.6156 | 0.8403 |
| CatBoost | 0.7559 | 0.5279 | 0.7594 | 0.6228 | 0.8381 |
| LightGBM | 0.7601 | 0.5344 | 0.7487 | 0.6236 | 0.8379 |
| XGBoost | 0.7622 | 0.5411 | 0.6872 | 0.6054 | 0.8282 |
| LightGBM с подбором Optuna | 0.7445 | 0.5119 | 0.8021 | 0.6250 | 0.8465 |

После подбора гиперпараметров LightGBM ROC-AUC увеличился с **0.8379** до **0.8465**. Recall оптимизированной модели составил **0.8021**, что помогает выявлять большую долю клиентов, склонных к оттоку.

## Датасет

**Telco Customer Churn**  
Источник: Kaggle  
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Датасет содержит сведения о клиентах телекоммуникационной компании: типе договора, подключённых услугах, способе оплаты, стаже обслуживания и платежах. Целевая переменная **Churn** показывает, ушёл ли клиент из компании.

В проекте используется файл `Telco-Customer-Churn.csv`.
